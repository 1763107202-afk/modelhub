# Engineering Research Suite

Version 0.3.1. 22 independently authored instruction adapters: six original engineering skills, screenshot-inspired academic workflows, and curated engineering, research and document workflows.

**No upstream software engines or MCP servers are bundled or connected.** GitHub CI tests packaging, not real mechanical or scientific outcomes. All upstream references and per-skill status are in `registry.json`.

Unverified screenshot labels such as Cortex Auto Research, Codex Cloud Academic Skills and respal-* are not misrepresented as original installs. Overlapping functionality is handled by independently written research workflow adapters.

Internal plugin ID stays `engineering-five-skills` for upgrades.

Build: `python scripts/build_plugin.py --output /tmp/engineering-five-skills-0.3.1.zip` (PyYAML required).

## Anti-Defensive Writing

The 22nd instruction-only skill is adapted from the Chinese MIT-licensed [Adkid-Zephyr/anti-defensive-writing-Skill](https://github.com/Adkid-Zephyr/anti-defensive-writing-Skill). It includes additional evidence-integrity protections for engineering reports and scientific research. No additional runtime or MCP server is connected.
