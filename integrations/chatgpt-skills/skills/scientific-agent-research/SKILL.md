# Scientific Agent Skills

## Workflow
1. Identify the user's objective, inputs, files, units, constraints and success criteria.
2. Determine which real tools and licensed software are available, and distinguish instructions from executable capabilities.
3. Specify an auditable workflow including sources, steps, parameters, error handling and expected artifacts.
4. Execute only with actually connected tools. Otherwise provide a reproducible plan rather than inventing results.
5. Check citations, calculations, geometry, convergence, document quality or simulation limitations relevant to the task.
6. Distinguish assumptions from measurements and actual tests, and explicitly report unresolved verification.
7. Provide exact outputs, evidence, versions and follow-up validation requirements.
