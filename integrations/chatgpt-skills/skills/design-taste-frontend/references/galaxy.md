# Galaxy / Uiverse 按需组件选型规范

## 资源与许可证
- 官方组件浏览：https://uiverse.io/
- 组件代码归档：https://github.com/uiverse-io/galaxy
- 上游仓库 README 描述为 MIT 许可证；引入单个代码片段前核对其实际来源、作者、许可证及必要的版权/许可说明。尽可能保留作者与 Uiverse.io 署名，不将网站素材或第三方内容的授权推定为相同。
- 此文档只提供使用流程，不捆绑 Galaxy 源码、爬虫、插件后端或任何依赖；不主张已实时接通 Uiverse 搜索。

## 触发条件与权限边界
1. 仅当用户要求 UI 设计、前端组件优化、代码实现，且现有项目组件不足以解决问题时，按需参考 Galaxy。
2. 纯机械设计、CAE、写作、论文、后端维护、普通问答不触发此资源检索。
3. 在现有 design-taste-frontend 内完成选型，Galaxy 是候选组件**来源**，不是新的独立设计 Skill，也不替换 Taste 风格审查。
4. 优先沿用项目已有组件、Token、框架、状态与交互行为。没有实际连接浏览器/仓库时，明确给出建议而非声称完成安装或测试。

## 组件选择和工程落地
- 首先定义组件目标与状态：默认、hover、focus-visible、disabled、loading、error、空状态。
- 搜索候选组件时仅取当前所需的 1–3 个片段；比较可读性、移动端布局、WCAG 可访问性、CSS/框架兼容性、动画开销和可维护性。
- 将色彩、圆角、尺寸、字号、动效接入现有设计 Token，禁止各页面拼凑随机风格。
- 复制入项目后限定 CSS 作用域；检查选择器污染、动画 keyframes 冲突、全局 reset、无效属性和重复依赖。React/Vue/桌面 WebView 应按项目框架封装，不应直接注入未知脚本。
- 组件必须使用语义化控件，检查键盘操作、可见焦点、对比度、屏幕阅读器标签、prefers-reduced-motion、移动端触控区域。
- 不加载不必要的外部 JS、追踪、远程字体和图片；遵守项目 CSP 和现有构建策略。避免增加主包尺寸、首屏阻塞和交互延迟。
- 用真实项目页面测窄屏/桌面宽度，以及成功、失败、权限不足和低速状态；若未执行测试则记录为“未验证”。

## 项目场景
- 实验室网站：消息、任务提交、进度卡片和导航，保持移动端易点击，保留老师/成员权限与提醒逻辑。
- Nexus：桌面 WebView 的项目卡、状态控件与悬浮窗；不改变工程文件路径或软件启动服务。
- 大葱机械演示站：设备状态指示、流程步骤、参数面板；UI 优化不得改变机构仿真/驱动逻辑。
- CAD 批量工具：导入区、计算状态、错误展示；不能用动画掩盖真实算法进度。

## 调用与验收记录模板
每次真正引入组件，在对应项目的变更说明中记录：
| 字段 | 内容 |
| --- | --- |
| 项目 / 页面 / 功能 | 项目名称与具体功能 |
| 来源 | Uiverse 或 Galaxy 精确 URL、原作者、检索日期 |
| 许可证 | 实际核对结果与需要保留的许可/署名 |
| 修改 | 使用的样式/逻辑、对应文件路径、依赖变化 |
| 兼容 | 框架版本、样式冲突与修复、移动端与 a11y |
| 性能 | CSS/JS 体积变化、是否额外网络请求 |
| 验收 | 已执行的检查、未覆盖范围、可回退提交 |

规则：先复用、再选择、后整合；没有合适组件就使用项目现有实现。不强制每个项目都引用 Galaxy。
