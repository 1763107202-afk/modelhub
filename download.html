ANDROID CLIENT

Android 手机版

面向手机使用优化，平台内部页面留在 App 内；外部链接交给系统浏览器，文件下载使用 Android 系统下载管理器。

下载 Android APK 返回网页版
APK 由 GitHub Actions 自动构建并发布。首次安装时，Android 可能要求允许当前浏览器“安装未知应用”，授权后即可继续安装。
IPHONE / IPAD

苹果用户添加到主屏幕

苹果设备无需安装 APK。建议使用 Safari 打开实验室平台，并将网页添加到主屏幕，之后可像普通 App 一样从桌面直接进入。

iPhone / iPad 推荐 Safari 无需下载安装包
1使用 Safari 浏览器 打开实验室交流平台主页。
2点击 Safari 底部或顶部的 分享按钮（方框向上箭头图标）。
3在分享菜单中向下找到并点击 “添加到主屏幕”。
4确认名称后点击右上角 “添加”，桌面就会出现实验室平台图标。
打开平台主页
以后直接点击桌面图标即可进入平台。若分享菜单里暂时没有“添加到主屏幕”，可向下滚动菜单查找该选项。
数据完全同步桌面端与网页版使用同一套 Supabase 数据，内容无需重复迁移。
网站更新即生效客户端直接加载线上平台，大多数网页功能更新后无需重新安装软件。
多端使用Windows 可固定到桌面，Android 可直接安装到手机，账号和数据保持一致。
