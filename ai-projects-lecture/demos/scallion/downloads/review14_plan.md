# 青葱工坊 R14 · 全流程三维方案

本版保留12工位旋转主体，4支一组，8秒设计分度周期。先更新网站，不输出SW。

## 流程

根向一致的采收载盘/上游定向输送 → 四槽输送带 → 切根/剪叶 → 根端托叉及分体笼翻转接管 → 主托座 → 两段去皮 → 清洗 → 沥水 → 两段风刀表面除水 → 四联卸料并翻平 → 自动供纸托 → 纵向鳍封及双端横封切断 → 四个独立检重带 → A/B四槽收集框 → 整框翻直 → 展开支脚 → 有限容量辊道缓存。

## 承托与保持

上料：输送面承重，根托叉接管后分体笼合围；主根托条接住后才释放源笼。包装：连续膜由制动/导辊/牵引轮保持，纵封与双端横封围成袋体；纸托承重，不靠膜与湿葱摩擦。成品：根端纸托落在实体端托上，双层框扶正，锁定支脚扩大底座；整个框随成品输出。

## 工程验证边界

- 输入接口为根向一致、尺寸分级的采收载盘/上游定向线。四联取料是自动动作；任意乱序缠绕散料的解缠与定向尚未验证。
- 示例单支原料长 720 mm，修整后 530 mm，茎部名义直径 28 mm。可调范围、叶片摆动包络和夹伤阈值待实测。
- 12 个分度工位，4 支/分度，设计节拍 8 s，理论 1800 支/h；不是实测合格产能。
- 膜采用适配蔬菜的透气/微孔热封膜，纸托支承叶部；纵封＋双端横封使袋体闭合，保鲜、冷凝和封口强度仍需验证。
- 风刀只对表面除水；风量、过滤等级、吹扫时间、残水指标与葱体损伤需以实料试验确定。
- 模型包含主要机架、轴系、传动、导轨、支承和固定管路；紧固件、密封、润滑、卫生细节及安全回路不等于生产图。
- 本版是机构方案和确定性运动演示，不是刚柔耦合仿真；不能用来宣称零干涉、食品卫生认证或可直接投产。
- 收集框需要下游清空、回洗与回供接口。演示含 16 框有限库存及满位停机；不宣称无限循环。

## 主要驱动与支承

- 分度：固定伺服减速机、小齿轮、环齿轮，中心回转轴承及环形支撑轮。
- 移载：径向双导轨/丝杠，双立柱升降/丝杠，侧置短轴翻转及同步带；根端托叉与两层分体笼。
- 托座：根底托条，背柱、滚轮轴、横向传动轴、蜗轮及滚轮同步带；工位固定头接合与退让。
- 介质：固定环形气/水总管和管卡，去皮头恒长折返软管，固定风刀与鼓风机，重力斜盘/滤篮/排污口。
- 包装：预制纸托升降料仓，推托导轨，膜卷/制动与导辊，成形肩，鳍封轮，四联横封梁与切刀。
- 检重：独立活动秤架、传感器、端辊及电机，柔性信号回路。
- 收集：A/B横移导轨，前后退让滑台，翻转轴承与制动伺服，侧仓升降供框，支脚及锁定，驱动辊道与缓存满位接口。

原理参考：FUJI蔬菜托盘枕式包装、Sonic食品风刀除水、Ishida多列检重；这些来源不验证本机性能。
