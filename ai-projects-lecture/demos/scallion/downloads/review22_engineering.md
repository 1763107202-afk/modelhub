# R22 横移轴装配与入口交接修订

本版是可审查的设计迭代，不是整机制造放行。旋转主体、四联加工、去皮自转、风刀除水、四列包装、检重与载框直立输出保留。未输出原生 SW 装配体。

## 本轮发现与修正

1. R21 的约 2.14 m 长、直径 12 mm 横移旋转丝杠没有导程、临界转速或轴承选型依据。不能按示意杆直接采购。八个横移轴改为同步带牵引、双导轨承重；短程折边升降丝杠暂时保留，尚待完整轴系校核。
2. R21 入料在横移小车尚未回到窄距时向小车送料。改为入口带先暂存，待回位后再送料，产品尾部完全离开固定带后才展距。入口驱动必须采用独立启停与位置确认；本版为运动与互锁设计，未生成 PLC 控制程序。
3. 单轴 CAD 检查发现底脚侵入带轮、转接腹板挡住螺栓、部分电机安装孔只钻入半厚度等问题，已按实际实体相交结果修改。未把这些接触简单排除。
4. 入口空车回程由 0.7 s 延长到 1.2 s，暂存送料配合调整，稳态仍按四支/8 s设计。实际产能、打滑与堵料率未验证。

## 名义横移轴参数

| 参数 | 本轮名义值 |
|---|---|
| 同步带轮 | 32齿，5 mm节距，160 mm/转 |
| 带轮中心距 | 2040 mm |
| 带节线长度 | 4240 mm，等价848个5 mm节距 |
| 带宽 | 15 mm；齿形、材料、加强芯及允许张力未选型 |
| 轴 | Ø12阶梯轴，4 mm键槽、独立键、隔套及端部定位 |
| 横移小车 | 双导轨承重，带夹块仅牵引 |
| 外侧列最大横移 | 720 mm |
| 入口展距 | 1.5 s，五次平滑位移 |
| 入口空车回程 | 1.2 s，五次平滑位移 |
| 出口并距 | 1.2 s，五次平滑位移 |

五次平滑曲线的峰值速度为 `1.875 S/T`，峰值加速度为 `10/√3 × S/T²`。最大720 mm、1.2 s动作得到峰值速度1.125 m/s、峰值加速度2.887 m/s²；带轮峰值421.875 rpm。数值只描述给定轨迹，不证明选型合格。

用于初筛的示例假设：等效移动质量5 kg、阻力20 N、旋转惯量0.0001 kg·m²、传动效率0.9。相应驱动力约34.4 N，未加系数的轴端转矩约0.99 N·m；按2倍系数约1.98 N·m。质量、张力、惯量、连续/峰值转矩、热负荷、带强度和轴承寿命都需根据实际型号重新计算，不能据此直接指定电机。

## 首组入口时序

| 时间 | 动作与承托 |
|---|---|
| 80–83 s | 入口带将根端从局部坐标2.32 m送到3.70 m |
| 83–86.2 s | 产品停在固定带，等待横移小车回到120 mm窄距 |
| 86.2–87.85 s | 入口与小车带同步，将根端送到4.32 m |
| 87.85–88 s | 产品全长进入小车，尾端离开固定带 |
| 88–89.5 s | 小车展距到600 mm包装列距 |
| 89.7–92.8 s | 送料进入包装机，尾端离开横移带 |
| 93–94.2 s | 空车回窄距，下一组按8 s偏移重复 |

## CAD 与检查边界

- 单轴161个CAD零件实例，八轴复用；另有8根对应安装孔的小车脊梁。零件由有效 BRep 生成网页网格，孔与槽不是绘制的黑点。采购电机、轴承及齿形仍含名义包络。
- CAD内部相交记录列出全部正体积接触，并逐对注明明确的螺纹包络配合；无其他未解释接触的名义姿态才通过。该检查只覆盖本轮CAD子集，不覆盖全线所有零件或连续旋转。
- 整线刚体检查沿用并扩充R21接口，新增横移轴对小车、转接座对原小车。具体采样和检测对数以 `review22_contacts.json` 为准。阈值、离散步长、柔性零件排除均在记录中说明。
- `review22_inventory.csv` 是整线**模型零件目录**，不是采购BOM。模型可能将一个实物拆成多个网格，也可能将采购组件作为单个包络，不能直接按目录计数采购。
- 新增单轴装配页面可选件、隔离及剖切；分解模式仅用于查看，不是已验证的装配/拆卸路径。
- 本轮云浏览器仍报 GL_VENDOR=Disabled / Error creating WebGL context。已验证目录搜索和选件说明；三维渲染、剖切及全线动画尚未完成浏览器验收。离线网格检查不能替代这一验收。
