# 极速词汇助手 Android 独立 APK 构建
本目录为**独立开发分支**下的构建项目，不改动 `main` 的实验室站点文件。

包含 ECDICT 英汉翻译 SQLite 离线词库（编译时从上游下载转换，超过十万条有中文译义的词）；独立的 AutoJs6 运行环境、悬浮窗口、OCR 与词义匹配。不是百词斩官方软件。

打开 [Actions](https://github.com/1763107202-afk/modelhub/actions) 查看 `Build FastQuiz Android APK`，成功的运行在 Artifacts 下可下载 `FastQuiz_Offline_APK`，里面为 APK。需要验证无障碍、OCR、界面尺寸及截屏权限；不保证匹配正确或能在真实排位运行。自动答题可能违反第三方服务条款。

源码仅供个人技术试验和词汇训练用途。
